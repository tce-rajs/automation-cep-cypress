How to start the remaining modules

Ordered by what is actually blocking each one, not by size. Wave 2 and 3 depend on other people — raise those requests today so they clear while Wave 1 is being built.

Before any of it — close the sync gap

cep-testrun is 7 files behind on the Quiz / Code Editor / Video rework, and is missing cypress/config/quizClass.js entirely — an import failure, not a soft mismatch. Run .\sync-from-main.ps1, confirm the list is exactly those 7, then -Apply. Clear the four stale allure-results-* folders, then npm run test:report.
